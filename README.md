# 夢限大みゅーたいぷ · 粉丝应援站

一个无需构建步骤的静态网页项目，展示夢限大みゅーたいぷ的成员、MV、二创精选与社区留言。

## 页面

- `index.html`：首页、成员图鉴、Bangumi 吐槽、二创精选与留言板
- `mv.html`：官方 MV / OP / ED 合集
- `fan.html`：二创排行榜与播放入口

## 本地预览

直接用浏览器打开 `index.html` 即可。若使用本地静态服务器，可获得接口与跨页面缓存的完整体验。

```bash
npx serve .
```

## 动态内容

- 二创页会按硬币率、点赞率生成榜单，并将当前精选同步至首页。
- 首页的 Bangumi 吐槽会定时刷新；接口不可用时会使用浏览器缓存与公开代理作为回退。
- 留言板支持服务端接口；纯静态部署时会保存在当前浏览器中，并在同源标签页间同步。
